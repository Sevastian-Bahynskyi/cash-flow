# Exemptions

The bounded register of patterns that look like a tell (`tells.md`) but are allowed.

## Rules

- **Not listed means not exempt.** A pattern that matches a tell and has no entry here is a finding, however deliberate a code comment says it is.
- **An entry is valid only with all five fields:** what, allowed scope, quota per screen, reason, owner sign-off date.
- **Only the owner adds, widens or revokes an entry.** An agent may propose one in a report or PR description. It never edits this file to make its own finding go away.
- **Scope and quota are hard limits.** A use outside them is a finding against the tell it matches.
