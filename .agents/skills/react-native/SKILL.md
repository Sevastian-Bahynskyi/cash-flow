# React Native

Use functional components and hooks, strict TypeScript, Expo Router, and the established Aura kit. Keep state local where possible. Use integer minor units for money and format at the UI edge.

Keep category picking fast, inputs controlled and errors visible. Handle loading, empty and offline data. Animation must leave controls ready to use.

For changed screens or interactions, use the [native fixture workflow](../../../docs/agents/ios-verification.md) and follow [UI / UX](../ui-ux/SKILL.md).
